# Pointer Jeans — E-commerce Customizations

**Live site:** [pointerjeans.in](https://pointerjeans.in/)

Website built and enhanced for a denim/jeans e-commerce brand — custom
sections, snippets, and theme customizations. Each one is documented as
a mini case study with code and screenshots.
